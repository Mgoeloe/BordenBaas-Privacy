# Privacybeleid BordenBaas

Publiek privacybeleid van **BordenBaas**, uitgegeven door **Untouchable Studios**.

**Gepubliceerde pagina:** https://mgoeloe.github.io/BordenBaas-Privacy/

**Privacycontact:** marlon+bordenbaas@leming.nl

## Publicatie

Deze repository gebruikt dezelfde GitHub Pages-inrichting als `Mgoeloe/Escape-Protocol-Privacy`:

- openbare repository;
- één zelfstandig `index.html` met ingebouwde CSS;
- publicatie vanuit `main`, map `/`;
- HTTPS;
- geen JavaScript, externe lettertypen, analytics of buildafhankelijkheden.

Pas `index.html` aan en werk de datum en, indien nodig, de beleidsversie bij. Een commit op `main` wordt door GitHub Pages gepubliceerd.

Gebruik de gepubliceerde pagina als rechtstreekse privacybeleid-URL in Google Play Console en het AdMob-privacybericht. GitHub Pages zelf verwerkt technische bezoekgegevens, zoals in het beleid beschreven.

## Inhoudelijke controle

Bij het opstellen op 24 oktober 2026 zijn de aangeleverde tekst en de daadwerkelijke lokale BordenBaas-broncode geraadpleegd, in het bijzonder opslag/reset, geschiedenis (maximaal 100 rondes), AdMob/UMP en Play Billing. Er zijn geen spelcode, SDK's of voortgangsbestanden gewijzigd.

Aanvullingen en verduidelijkingen:
- ontwikkelaarsidentiteit en het opgegeven BordenBaas-contactadres;
- geen eigen telemetrie, met onderscheid tussen lokale voortgang en Google-SDK-diagnostiek;
- toestemming bij niet-gepersonaliseerde advertenties en de afzonderlijke UMP-controle;
- vrijwillige rewarded-video's en aankoopcontroles na “Advertenties verwijderen”;
- volledige lokale reset versus behoud van monetisatietellers;
- bewaartermijnen, contactcorrespondentie, beveiliging en internationale doorgifte;
- GitHub Pages-hosting en het ontbreken van eigen website-tracking.

De advertentie-, toestemmings- en aankoopintegraties zijn voor deze publicatie aan de hand van code en officiële documentatie beoordeeld. Er zijn hierbij geen fysieke Android-/Play Store-tests uitgevoerd en geen Play Console- of AdMob-instellingen gewijzigd.
